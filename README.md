1. Главный сценарий: Добавление чека (1 сообщение)

Пользователь просто открывает чат и отправляет текстовое сообщение в свободном формате. Бот сам понимает сумму, описание и тип операции.
Как это выглядит для пользователя:

    Пользователь пишет: 350 кофе или 15000 фриланс или 2500

    Бот мгновенно сохраняет запись и отвечает коротким сообщением (которое автоматически удаляется или скрывается, чтобы не замусоривать чат):

        ✅ Расход сохранен: 350.00 ₽ (Прочие расходы)

        💳 Баланс: 45 600.00 ₽

        🔘 [ Изменить категорию ] [ Отменить (15 сек) ]

Как работает парсинг текста под капотом (Регулярные выражения / Regex):

    Пример 1: 350 кофе

        Находит первое число (350) -> value = 350.0

        Все остальное (кофе) -> desc = "кофе"

        По умолчанию ставит тип Расход (так как 90% частых транзакций — это расходы).

    Пример 2: +15000 аванс (знак + явно указывает на Доход)

        value = 15000.0, desc = "аванс", Status = True (Доход).

    Пример 3: 2500

        value = 2500.0, desc = "Прочие расходы".

2. Структура меню бота (Reply Keyboard / Постоянные кнопки)

Внизу экрана всегда висит компактная клавиатура из 3-4 основных кнопок, чтобы не нужно было писать /start или искать команды в меню:

+-------------------------------------------------+
|  📊 Аналитика за месяц  |   💳 Мой баланс       |
+-------------------------+-----------------------+
|  📜 Последние операции  |   ⚙️ Настройки        |
+-------------------------------------------------+

Назначение кнопок:

    📊 Аналитика за месяц

    Выводит краткую сводку в одно сообщение со свернутыми подробностями:

        📅 Отчет за Август 2026

        🟢 Доходы: 85 000 ₽

        🔴 Расходы: 42 300 ₽

        💰 Чистый результат: +42 700 ₽

        🔘 [ ◀ Июль ] [ Детализация по категориям ] [ Сформировать PDF/Excel ]

    💳 Мой баланс

    Показывает текущий остаток и быстрый переход к корректировке:

        💳 Текущий баланс: 124 500 ₽

        🔘 [ ✏ Изменить текущий баланс ]

    📜 Последние операции

    Выводит список из последних 5-7 чеков с кнопками быстрых действий (например, удаление случайного ввода):

            02.08 — 350 ₽ (кофе) ❌

            02.08 — 1 200 ₽ (продукты) ❌

            01.08 — +15 000 ₽ (фриланс) ❌

    ⚙️ Настройки

        Управление категориями: Добавить/удалить синонимы категорий (например, чтобы слова "такси", "метро", "автобус" автоматически размещались в категорию "Транспорт").

        Валюта: По умолчанию ₽, $, €.

        Напоминания: Настройка ежедневного пуш-уведомления вечером в 21:00 («Не забудь записать сегодняшние расходы!»).
