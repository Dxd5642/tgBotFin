# finAnalysisBot

Telegram-бот для учёта личных финансов: доходы, расходы, баланс, категории, аналитика за месяц и зарезервированные счета.

## Что умеет бот

- регистрация с начальным балансом (`/start`);
- добавление операции обычным сообщением: сумма и описание;
- доход — сумма с `+` в начале (`+15000 зарплата`);
- автовыбор категории по ключевым словам (магазины, такси, подписки и т.д.);
- подтверждение, правка категории или отмена перед записью;
- аналитика за месяц (текст + график);
- текущий баланс;
- список последних операций;
- Excel-отчёт по чекам за месяц;
- резервные счета: лимит по категории, период, пополнение, смена даты, удаление.

Если описание не указано, операция попадает в категорию «Прочее».

## Стек

| Назначение | Библиотека |
|---|---|
| Telegram-бот | [aiogram](https://docs.aiogram.dev/) 3.x |
| БД | SQLite + [SQLAlchemy](https://www.sqlalchemy.org/) |
| Конфиг | `python-dotenv` |
| Excel-отчёт | pandas, openpyxl |
| Подбор категории | rapidfuzz |
| Графики | matplotlib |

Python 3.10+.

## Запуск

1. Клонируйте репозиторий и перейдите в папку проекта.

2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
pip install -r requirements.txt
```

Linux / macOS:

```bash
source venv/bin/activate
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта и укажите токен бота от [@BotFather](https://t.me/BotFather):

```env
BOT_TOKEN=123456:ABC-your-telegram-bot-token
```

4. Запустите бота:

```bash
python main.py
```

При старте инициализируется SQLite, создаются таблицы, статусы операций и категории. В консоли появится сообщение о запуске. Дальше откройте бота в Telegram и отправьте `/start`.

## Как пользоваться

1. `/start` или `/menu` — главное меню.
2. При первом входе введите начальный баланс числом.
3. Чтобы записать расход: `450 пятерочка` или `1200 такси`.
4. Чтобы записать доход: `+50000 зарплата`.
5. Подтвердите операцию или смените категорию кнопками.
